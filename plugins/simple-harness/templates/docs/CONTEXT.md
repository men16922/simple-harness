# 현재 상태

## 목표와 완료 조건
- 목표: 미정 — 사용자가 원하는 결과를 설명하면 Agent가 구체화한다.
- 완료 조건: 미정 — 실제 사용자가 확인할 수 있는 동작으로 작성한다.

## 환경과 제약
- 언어/프레임워크: 기존 프로젝트 확인 후 선택한다.
- 작업 환경: 로컬 개발. 외부 시스템 변경은 승인 범위를 따른다.
- 프로젝트별 제약: 아직 확인하지 않음.

## 실행과 검증
- 실행 명령: 아직 확인하지 않음.
- 검증 명령: 아직 확인하지 않음. Agent가 프로젝트에서 찾아 기록한다.
- 최근 결과: 미검증.

## 진행 상태
- 완료: 없음.
- 진행 중/막힌 점: 요구사항을 아직 받지 않음.

## 다음 행동
사용자의 목표를 구체화하고, 현재 파일과 실행 환경을 확인한 뒤 첫 기능을 구현한다.
