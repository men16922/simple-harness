name: sync
description: '"sync", "이어서 하자", "어디까지 했지"에서 목표와 다음 작업을 복원한다. "하네스 준비해줘"에서만 프로젝트에 지침과 기록 문서를 만든다.'
---

1. 준비를 명시적으로 요청받았을 때만 파일을 준비한다. sync 직접 호출만으로는 만들지 않는다.
   템플릿은 이 스킬 기준 `../../templates/`. 기존 내용과 프로젝트의 기록 경로를 보존한다.
   - 쓰기는 Codex의 `apply_patch`, Claude의 `Write`·`Edit` 등 파일 도구만 쓴다.
     셸·Python·스크립트로 쓰거나 도구를 설치하지 않는다. 파일 도구가 없으면 준비하지 못했다고 알린다.
   - 파일별로 확인한다. `AGENTS.md`가 없으면 복사하고, 있으면
     `<!-- simple-harness:start -->` 블록이 없을 때만 끝에 덧붙인다.
   - `CLAUDE.md`가 없으면 `@AGENTS.md` 한 줄로 만든다. 그 줄이 없고 `AGENTS.md`
     링크도 아니면 끝에 덧붙인다.
   - 기록 문서는 없는 것만 복사한다. 지침 블록이 이미 있어도 누락된 파일은 준비한다.
2. 준비 요청이 없으면 파일을 만들지 않는다. 기록 문서가 없으면 README와 Git 상태로
   상황을 파악하고, "하네스 준비해줘"로 준비할 수 있다고 한 줄 안내한다.
   `docs/CONTEXT.md`가 있으면 읽는다(이번 세션에 읽었고 안 바뀌었으면 생략).
   Git이면 `git status --short --branch`와 `git log --oneline -3`을 본다.
   코드와 문서가 다르면 코드를 기준으로 알린다.
3. 다음 행동이 불명확할 때만 기존 `docs/WORKLOG.md` 최신 2개와 관련 파일을 읽는다.
4. 목표·현재 상태·마지막 검증·다음 행동·막힌 점을 5줄 안팎으로 알린다. 목표가
   비었으면 무엇을 만들지 하나만 묻는다. 구현도 요청받았으면 바로 진행한다.
