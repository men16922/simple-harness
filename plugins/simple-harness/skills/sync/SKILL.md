name: sync
description: '"sync", "이어서 하자", "어디까지 했지"에서 목표와 다음 작업을 복원한다. "하네스 준비해줘"에서만 프로젝트에 지침과 기록 문서를 만든다.'
---

1. 프로젝트 지침에 `<!-- simple-harness:start -->`가 없으면:
   - 준비를 요청받았거나 직접 호출됐다면 파일 도구로 준비한다. 템플릿은 이 스킬 기준
     `../../templates/`. 기존 내용은 고치지 않는다. 자체 Agent 지침이 있으면 무엇을
     덧붙일지 알리고 동의를 받는다.
     - `AGENTS.md`, `docs/CONTEXT.md`, `docs/WORKLOG.md`: 없으면 복사. `AGENTS.md`가
       있으면 끝에 템플릿 블록을 한 번 덧붙인다.
     - `CLAUDE.md`: 없으면 `@AGENTS.md` 한 줄로 만든다. 그 줄이 없고 `AGENTS.md`
       링크도 아니면 끝에 덧붙인다.
   - 아니면 파일을 만들지 말고 "하네스 준비해줘"로 준비할 수 있다고 한 줄 안내한다.
2. `docs/CONTEXT.md`를 읽는다(이번 세션에 읽었고 안 바뀌었으면 생략).
   Git이면 `git status --short --branch`와 `git log --oneline -3`을 본다.
   코드와 문서가 다르면 코드를 기준으로 알린다.
3. 다음 행동이 불명확할 때만 `docs/WORKLOG.md` 최신 2개와 관련 파일을 읽는다.
4. 목표·현재 상태·마지막 검증·다음 행동·막힌 점을 5줄 안팎으로 알린다. 목표가
   비었으면 무엇을 만들지 하나만 묻는다. 구현도 요청받았으면 바로 진행한다.
