---
name: tidy-docs
description: '"문서 정리해줘", "tidy-docs" 또는 작업 문서가 예산을 넘을 때 원문을 아카이브에 보존하고 줄인다.'
---

1. 대상은 `docs/CONTEXT.md`와 `docs/WORKLOG.md`(프로젝트 지침에 다른 경로가 있으면 그것).
   없는 문서는 건너뛴다. 예산은 프로젝트 지침을 따르고, 없으면 이 스킬 기준
   `../../templates/AGENTS.md`의 문서 예산을 읽는다. 넘지 않으면 끝낸다.
2. CONTEXT에는 목표·완료 조건·제약·검증법·최근 결과·미해결 문제·다음 행동만 남기고,
   끝난 작업의 상세는 WORKLOG로 옮긴다.
3. WORKLOG는 최신 2~3개만 남기고 나머지는 `docs/archive/YYYY-MM.md`에 원문 그대로
   덧붙인다. 기존 아카이브는 덮어쓰지 않는다.
4. 아카이브에 원문이 저장됐는지 확인한 뒤에 줄인다. 요구사항·미해결 문제·검증 증거는
   버리지 않는다. 줄여도 넘으면 보존하고 초과를 알린다.
5. 바뀐 파일과 전후 분량을 짧게 알린다.
